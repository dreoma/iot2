# Ручная проверка доставки

Импортируйте notifications.postman_collection.json в Postman. В коллекции
«IoT2 — уведомления Email + Telegram» откройте Variables и заполните:

- notify_mail — адрес получателя;
- notify_password — пароль этой учётной записи. Заполните локальное значение.

Персональные значения оставлены пустыми. Проверка входных переменных не даст
случайно отправить запросы с незаполненными получателями.

Если учётной записи ещё нет, выполните три запроса из папки «Регистрация новой
учётной записи». После первого запроса откройте `telegram_url` из ответа,
нажмите «Старт» в личном чате и дождитесь `telegram_confirmed: true`.
Пользователю, созданному до появления входа, оператор назначает
пароль по [инструкции](../iot-core/README.md#пароли-для-существующих-пользователей).

В папке 01 по порядку выполните вход, проверку контактов и остальные запросы.
Коллекция сохраняет токен и ID автоматически. При ошибке запроса остановитесь
и проверьте ответ. Храните пароль и токен только в локальных значениях Postman.

Запрос 05 инициирует отправку в оба настроенных канала. Для нового сообщения
выполните папку 02: сначала 25 °C, затем 40 °C. Температура 36 после 35 не должна
создавать дубль. История уведомлений подтверждает правило, но не доставку.

Настройки сервера в .env:

    IOT_TELEGRAM_BOT_TOKEN=токен_от_BotFather
    IOT_SMTP_URL=smtps://ваш_сервер:465
    IOT_SMTP_USER=ваш_логин
    IOT_SMTP_PASSWORD=ваш_пароль_приложения
    IOT_SMTP_FROM=адрес_отправителя

Бот запоминает Telegram ID при подтверждении регистрации. Токен бота и пароль
SMTP остаются в `.env`. Для включения изменений сервера:

    docker compose up -d --force-recreate iot-core

По умолчанию SMTP направлен в локальный Mailpit: http://localhost:8025.
Если оставить smtp://mailpit:1025, письмо не придёт в настоящий внешний ящик,
даже если в notify_mail введён настоящий адрес. Для него нужен внешний SMTP.

Проверка сертификата отключена только для запросов этой локальной коллекции.
Набор не запускается автоматически: получателей и отправку задаёт пользователь.
