# IoT Studio

Интерфейс на Vue 3 и Vite использует API `iot-core`. В нём доступны регистрация,
вход, выход, создание устройств, поиск и история измерений. Пока вкладка открыта
и видима, показания обновляются каждые 15 секунд. Токен хранится в
`sessionStorage` и переживает перезагрузку текущей вкладки. По истечении сессии
интерфейс предлагает войти снова.

Для регистрации в `.env` нужен `IOT_TELEGRAM_BOT_TOKEN` от BotFather. В форме
введите почту, откройте бота по ссылке и нажмите «Старт». Когда сайт получит
подтверждение из Telegram, он покажет поле для пароля. Ссылка действует 10 минут,
а начатую регистрацию можно продолжить после перезагрузки той же вкладки.

## Запуск в Docker

Запускайте команды из корня проекта. Для нового окружения сначала выполните
[настройку .env и сертификатов](../LOCAL_SETUP.md).

```sh
docker compose up --build -d
```

Откройте https://localhost:8443/app/. Nginx раздаёт фронтенд и проксирует API
через тот же HTTPS-адрес. Браузер должен доверять локальному CA
`certs/ca.crt`. Если серверный сертификат был создан старой версией скрипта
только для имени `core-tls`, обновите его с тем же CA и пересоздайте прокси:

```sh
sh scripts/generate-certs.sh --renew-server
docker compose up -d --build --force-recreate core-tls
```

## Разработка

Оставьте Docker Compose запущенным. Из корня проекта выполните:

```sh
npm ci --prefix front
npm run dev --prefix front
```

Откройте адрес Vite из терминала, по умолчанию http://127.0.0.1:5173/app/.
Сервер разработки доступен на loopback. Он проверяет сертификат `core-tls`
через `certs/ca.crt` при пересылке запросов к API.

Чтобы увидеть показания, возьмите ID созданного устройства из интерфейса
и отправьте тестовый пакет в адаптер, подставив это значение вместо `1`:

```sh
curl -fsS http://127.0.0.1:8081/telemetry \
  -H 'Content-Type: application/json' \
  -d '{"device_id":1,"data":{"temperature":22.5,"humidity":48}}'
```

Нажмите «Обновить» или дождитесь следующего опроса. История показывает
30 последних измерений, а числовой график появляется после двух показаний
одного поля. Статус «Есть данные» означает наличие сохранённого измерения.
